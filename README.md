# Engineering Services Project Hub

City of Whitehorse - Engineering Services. Single-page app (index.html) with a left menu:
Home, Chart Org, and Generate pages (FMW monitor, Drawing, ITB, Pre-bid query, Bid,
Evaluation & Award, Material Submission, Health & Safety Traffic Plan, Public Service
Announcement, Construction Schedule, Invoice & payment recommendation).

Note: AI extraction/drafting, shared storage and file download use the Claude artifact
runtime (window.claude), so those features work only when the page is published as a
Claude artifact.
